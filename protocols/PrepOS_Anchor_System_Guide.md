## Purpose

This document serves as the long-term canonical reference for the PrepOS Anchor System.

It is intended to:
- preserve architectural philosophy,

- guide future cognition-layer expansion,
- stabilize long-term semantic evolution.

---

# 1. Anchor System Philosophy

The PrepOS Anchor System replaces the old hyperlink ontology.

Old model:

Entity → Destination

PrepOS model:

Entity → Cognition Surface → Optional Deep Expansion

Anchors are not simple hyperlinks.

They are semantic cognition surfaces.

The system is designed for:
- educational cognition,
- semantic stabilization,
- retrieval reinforcement,
- low-friction conceptual clarification.

PrepOS is NOT Wikipedia.

Meaning remains primary.

---

# 2. Core Anchor Interaction Model

Correct semantic interaction flow:

Anchor
↓
Anchor Inspector
↓
Anchor Note
↓
Optional Canonical Expansion

NOT:

Anchor
↓
Direct Canonical Navigation

Canonical notes are secondary deep-expansion layers.

Anchor notes are primary cognition layers.

# 3. Anchor Fundamentals

## What Is An Anchor?

An Anchor is a reusable semantic entity in PrepOS.

Examples:
- Parliament
- Magna Carta
- Rule of Law
- Puritans
- Ship Money

Anchors are globally reusable semantic infrastructure.

---

# 4. Anchor Types

## Micro Anchors

Contain:
- Anchor Note only

Purpose:
lightweight semantic cognition.

---

## Canonical Anchors

Contain:
- Anchor Note
- Canonical Topic Linkage

Flow:

Anchor
↓
Anchor Note
↓
Open Canonical Note

Canonical notes are never opened directly from inline semantic interaction.

---

# 5. Anchor Notes

## Purpose

Anchor Notes provide:
- rapid clarification,
- retrieval stabilization,
- contextual reinforcement,
- low-cost semantic expansion.

They preserve reading flow.

---

## Anchor Note Design Philosophy

Anchor notes should be:
- concise,
- retrieval-oriented,
- educationally lightweight,
- semantically focused.

Avoid:
- essay-scale detail,
- excessive chronology,
- semantic sprawl.

Anchor notes answer:

"What does the learner immediately need?"

NOT:

"What is everything about this topic?"

---

# 6. Anchor Lifecycle

## Candidate Anchors

MSMDF declares semantic entities using:

[[Entity]]

Parser then resolves:
- existing
- canonical
- candidate
- dormant
- alias
- unresolved

Candidate anchors are unresolved semantic entities.

---

## Existing Anchors

Permanent semantic entities already recognized by PrepOS.

---

## Dormant Anchors

Dormant anchors:
- remain preserved globally,
- disappear from published interaction,
- remain visible in draft governance.

Dormancy exists because anchors are reusable semantic infrastructure.

Deletion is avoided.

---

# 7. Anchoring and De-Anchoring

## Anchoring

Promotes semantic candidates into permanent semantic infrastructure.

---

## De-Anchoring

Transitions active anchors into Dormant State.

Published readers see:
plain text.

Draft governance still visualizes dormant semantic state.

---

# 8. Parser Integration

Pipeline:

MSMDF
↓
parseMapMarkdown()
↓
attachSemanticCandidates()
↓
resolveAnchorCandidates()
↓
semanticMap
↓
semantic rendering

The parser does NOT assume every [[Entity]] already exists.

It performs semantic resolution.

# 9. Semantic Rendering

## Draft Semantic Rendering

Draft preview acts as:
semantic governance environment.

Visual states:

- Existing → blue underline
- Canonical → enhanced semantic emphasis
- Candidate → purple dashed underline
- Dormant → muted gray
- Unresolved → plain text

---

## Published Semantic Rendering

Published reading is cognition-first.

Only active semantic anchors remain interactive.

Candidate and dormant anchors become plain text.

# 12. Semantic Reading Ergonomics

## Meaning Before Interaction

Semantic systems must support:
- comprehension,
- continuity,
- retrieval,
- reading calmness.

Interaction must never dominate reading.

---

## Repeated Anchor Softening

Repeated anchors remain interactive but visually softened.

Purpose:
reduce semantic fatigue.

---

## Reading Context Restoration

Closing inspectors restores reading position.

Purpose:
preserve cognition continuity.
