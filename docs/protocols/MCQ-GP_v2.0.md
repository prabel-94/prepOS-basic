# 📘 MCQ-GP v2.0 (Multiple Choice Question Generation Protocol)

## Purpose
To systematically generate a complete MCQ question bank ensuring:
- full concept coverage
- multiple formats
- trap inclusion
- exam alignment

---

## CORE PRINCIPLE

The goal is NOT to create many questions.

The goal is to **EXHAUST THE CONCEPT SPACE**.

---

## STAGE 1: CONCEPT EXTRACTION

### Input
- Textbook / Notes / Source material

### Process
Break content into atomic concepts:

- facts
- definitions
- principles
- relationships
- case laws
- exceptions

Each concept → **Question Unit**

---

## STAGE 2: QUESTION GENERATION MODULES

### MODULE 1: DIRECT MCQ
- Tests factual recall

---

### MODULE 2: STATEMENT MCQ
- “Consider the following statements”
- Mix correct + incorrect
- Include partial truths

---

### MODULE 3: CONCEPTUAL MCQ
- Tests role/function/interpretation

---

### MODULE 4: MATCH THE FOLLOWING
- Use for associations:
  - thinkers
  - articles
  - features

---

### MODULE 5: ASSERTION–REASON
- Tests logic
- Check if R explains A

---

### MODULE 6: TRAP GENERATION

Techniques:

1. Absolute words (only, always)
2. Reversal (e.g., “Preamble gives power”)
3. Partial truth
4. Concept confusion

---

## STAGE 3: COVERAGE RULE

For EACH concept:

### Mandatory
- 1 Direct MCQ
- 1 Statement MCQ
- 1 Trap Question

### Optional
- Conceptual
- Match
- Assertion

---

## STAGE 4: QUESTION DISTRIBUTION

Ensure inclusion of:

- Direct
- Statement
- Conceptual
- Match
- Assertion
- Trap

---

## STAGE 5: DIFFICULTY BALANCING

Include:

- Easy → factual
- Moderate → conceptual
- Hard → reasoning
- Trap → misleading

---

## STAGE 6: QUALITY CHECK

Each question must be:

- Clear
- Unambiguous
- Single correct answer
- Concept-linked
- Exam relevant

---

## STAGE 7: EXPLANATION STANDARD

Each explanation must include:

1. Why correct
2. Why others wrong
3. Concept reinforcement

---

## INTEGRATION WITH PCP

- MCQ-GP runs AFTER PCP
- Questions must map to notes

Bidirectional flow:

Notes → Questions  
Questions → Notes  

---

## OUTPUT

Each topic produces:

- Multi-format question bank
- Balanced difficulty
- Full concept coverage
