# ഇംഗ്ലീഷ് വിപ്ലവം (1603–1689)

# ഒറ്റവരി റിവിഷൻ

ഇംഗ്ലീഷ് വിപ്ലവം (1603–1689), **ദൈവിക രാജാധികാരം (Divine Right)** അവകാശപ്പെട്ടിരുന്ന രാജവാഴ്ചയെ **പാർലമെന്റിന്റെ പരമാധികാരവും (Parliamentary Sovereignty)** **നിയമവാഴ്ചയും (Rule of Law)** അടിസ്ഥാനമാക്കിയ **ഭരണഘടനാപരമായ രാജവാഴ്ചയായി (Constitutional Monarchy)** രൂപാന്തരപ്പെടുത്തി.

# 12. അന്തിമ റിവിഷൻ വാക്യം

**ഇംഗ്ലീഷ് വിപ്ലവം വെറും രാജാവും പാർലമെന്റും തമ്മിലുള്ള അധികാരസമരം മാത്രമായിരുന്നില്ല. നൂറ്റാണ്ടുകളായി നടന്ന ഭരണഘടനാപരമായ വികാസത്തിന്റെ പര്യവസാനമായി അത് രാഷ്ട്രീയപരമാധികാരം രാജാവിൽ നിന്ന് പാർലമെന്റിലേക്ക് മാറ്റി, നിയമവാഴ്ചയും ഭരണഘടനാപരമായ രാജവാഴ്ചയും സ്ഥാപിച്ചു, ആധുനിക ലിബറൽ ജനാധിപത്യത്തിന്റെ ഭരണഘടനാപരവും ബൗദ്ധികവുമായ അടിത്തറ പാകി.**
