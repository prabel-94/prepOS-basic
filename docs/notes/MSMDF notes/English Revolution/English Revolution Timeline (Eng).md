# English Revolution (1603–1689)

> **Timeline Purpose**
>
> This Timeline Layer reorganizes the English Revolution into a strictly chronological sequence. Unlike the Narrative Layer, which explains the historical story, the Timeline emphasizes temporal order, historical progression, and cause–effect relationships. It is designed to strengthen chronological retrieval, event sequencing, and examination recall without repeating conceptual explanations.
