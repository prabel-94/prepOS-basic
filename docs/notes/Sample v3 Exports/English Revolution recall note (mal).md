# [RECALL]
# ഇംഗ്ലീഷ് വിപ്ലവം (1603–1689)

# 1. നേരിട്ടുള്ള ഓർമ്മവിളി (Direct Recall)

1. രാജാവ് നിയമത്തിന് വിധേയനാണെന്ന തത്വം ആദ്യമായി സ്ഥാപിച്ച രേഖ ഏത്?
   → [[Magna Carta]]

2. [[Church of England]] സ്ഥാപിച്ച ഇംഗ്ലീഷ് രാജാവ് ആര്?
   → [[Henry VIII]]

3. [[Divine Right Theory]] ശക്തമായി പ്രചരിപ്പിച്ച സ്റ്റുവർട്ട് രാജാവ് ആര്?
   → [[James I]]

4. പാർലമെന്റിന്റെ സമ്മതമില്ലാതെ നികുതി ചുമത്തരുതെന്ന് ആവശ്യപ്പെട്ട രേഖ ഏത്?
   → [[Petition of Right]]

5. ഏകാധിപത്യ രാജവാഴ്ചയുടെ പ്രതീകമായി മാറിയ നികുതി ഏത്?
   → [[Ship Money]]

6. High Anglican പരിഷ്കാരങ്ങൾക്ക് നേതൃത്വം നൽകിയ ആർച്ച് ബിഷപ്പ് ആര്?
   → [[William Laud]]

7. "Eleven Years' Tyranny" എന്നറിയപ്പെടുന്ന ഭരണകാലം ഏത്?
   → [[Personal Rule]]

8. [[Grand Remonstrance]] പുറത്തിറക്കിയ പാർലമെന്റ് ഏത്?
   → [[Long Parliament]]

9. ആഭ്യന്തരയുദ്ധത്തിലെ നിർണായക പാർലമെന്ററി വിജയം ഏത് യുദ്ധത്തിലായിരുന്നു?
   → [[Battle of Naseby]]

10. ഇംഗ്ലീഷ് ആഭ്യന്തരയുദ്ധത്തിന്റെ ഗതി മാറ്റിയ പ്രൊഫഷണൽ സൈന്യം ഏത്?
    → [[New Model Army]]

11. രാജവാഴ്ചയുടെ വിശുദ്ധതയെ ചോദ്യം ചെയ്ത ചരിത്രസംഭവം ഏത്?
    → [[Execution of Charles I]]

12. രാജവാഴ്ചയ്ക്ക് പകരം സ്ഥാപിക്കപ്പെട്ട റിപ്പബ്ലിക്കൻ ഭരണസംവിധാനം ഏത്?
    → [[Commonwealth]]

13. [[Protectorate]] സ്ഥാപിച്ച ലിഖിത ഭരണഘടന ഏത്?
    → [[Instrument of Government]]

14. [[Restoration]]ന് വഴിയൊരുക്കിയ പ്രഖ്യാപനം ഏത്?
    → [[Declaration of Breda]]

15. അന്യായ തടങ്കലിനെതിരായ നിയമപരമായ സംരക്ഷണം ശക്തിപ്പെടുത്തിയ നിയമം ഏത്?
    → [[Habeas Corpus Act]]

16. [[Whigs]]യും [[Tories]]യും രൂപംകൊള്ളാൻ കാരണമായ രാഷ്ട്രീയ പ്രതിസന്ധി ഏത്?
    → [[Exclusion Crisis]]

17. [[James II]]നെ മാറ്റി ഇംഗ്ലണ്ടിലേക്ക് ക്ഷണിക്കപ്പെട്ടത് ആര്?
    → [[William of Orange]]

18. പാർലമെന്റിന്റെ മേൽക്കോയ്മ സ്ഥിരമായി സ്ഥാപിച്ച വിപ്ലവം ഏത്?
    → [[Glorious Revolution]]

19. 1688-ന് ശേഷം രാജാധികാരത്തെ സ്ഥിരമായി നിയന്ത്രിച്ച ഭരണഘടനാപരമായ രേഖ ഏത്?
    → [[Bill of Rights]]

20. സ്വാഭാവിക അവകാശങ്ങളെയും പരിമിത സർക്കാരിനെയും തത്ത്വചിന്താപരമായി ന്യായീകരിച്ച ചിന്തകൻ ആര്?
    → [[John Locke]]

# 3. ബന്ധ ഓർമ്മവിളി (Relationship Recall)

1. [[Ship Money]] എന്തുകൊണ്ടാണ് വിവാദമായത്?
   → പാർലമെന്റിന്റെ സമ്മതമില്ലാതെ നികുതി ചുമത്തിയതിനാൽ.

2. [[Charles I]] 1640-ൽ വീണ്ടും പാർലമെന്റിനെ വിളിക്കേണ്ടിവന്നത് എന്തുകൊണ്ട്?
   → [[Bishops' Wars]] മൂലമുണ്ടായ സാമ്പത്തിക പ്രതിസന്ധി കാരണം.

3. [[New Model Army]] ചരിത്രപരമായി പ്രധാനമായത് എന്തുകൊണ്ട്?
   → കർശന അച്ചടക്കമുള്ള പ്രൊഫഷണൽ സൈന്യമായി മാറി പാർലമെന്റിന്റെ വിജയത്തിന് നിർണായകമായതിനാൽ.

4. [[Putney Debates]] ചരിത്രപരമായി പ്രധാനപ്പെട്ടത് എന്തുകൊണ്ട്?
   → ജനപരമാധികാരത്തെയും ജനപ്രതിനിധി ഭരണത്തെയും കുറിച്ചുള്ള ആദ്യകാല പ്രധാന സംവാദമായതിനാൽ.

5. [[Bill of Rights]] ഭരണഘടനാപരമായ നാഴികക്കല്ലായി കണക്കാക്കപ്പെടുന്നത് എന്തുകൊണ്ട്?
   → രാജാധികാരത്തിന് സ്ഥിരമായ ഭരണഘടനാപരമായ നിയന്ത്രണങ്ങൾ ഏർപ്പെടുത്തി പാർലമെന്റിന്റെ മേൽക്കോയ്മ ഉറപ്പാക്കിയതിനാൽ.

# 6. വ്യാഖ്യാന ഓർമ്മവിളി (Interpretation Recall)

1. ഇംഗ്ലീഷ് വിപ്ലവത്തെ ഭരണഘടനാപരമായ സ്വാതന്ത്ര്യത്തിലേക്കുള്ള നിരന്തര പുരോഗതിയായി കാണുന്ന ചരിത്രവ്യാഖ്യാനം ഏത്?
   → Whig വ്യാഖ്യാനം

2. ഇംഗ്ലീഷ് വിപ്ലവത്തെ ബൂർഷ്വാ വിപ്ലവമായി കാണുന്ന ചരിത്രവ്യാഖ്യാനം ഏത്?
   → Marxist വ്യാഖ്യാനം

3. രാഷ്ട്രീയ സാഹചര്യങ്ങൾ, മതസംഘർഷങ്ങൾ, വ്യക്തികളുടെ തീരുമാനങ്ങൾ എന്നിവയ്ക്ക് കൂടുതൽ പ്രാധാന്യം നൽകുന്ന ചരിത്രവ്യാഖ്യാനം ഏത്?
   → Revisionist വ്യാഖ്യാനം

# 7. സമഗ്ര പുനർനിർമ്മാണം (Integrated Reconstruction)

1. 1215 മുതൽ 1701 വരെ ഇംഗ്ലണ്ടിന്റെ ഭരണഘടനാപരമായ വികാസം പ്രധാന ഭരണഘടനാപരമായ രേഖകൾ ഉപയോഗിച്ച് പുനർനിർമ്മിക്കുക.

2. ഭരണഘടനാപരമായ സംഘർഷവും മതപരമായ സംഘർഷവും ചേർന്ന് ഇംഗ്ലീഷ് വിപ്ലവത്തിന് എങ്ങനെ വഴിയൊരുക്കിയെന്ന് വിശദീകരിക്കുക.

3. [[Personal Rule]] മുതൽ [[Bill of Rights]] വരെ നടന്ന രാഷ്ട്രീയവികാസം വിശദീകരിക്കുക.
